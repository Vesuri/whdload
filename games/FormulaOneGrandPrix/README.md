# F1GP

Workspace for a future investigation of the Amiga game Formula One Grand Prix.
Only project setup and input preparation are complete; analysis has not started.

The supplied four-disk installation uses Codetapper's v1.0 WHDLoad slave.
No slave source is available. No emulator launcher or reconstructed slave has
been created, and no game or slave binaries have been analysed.

- [Development setup](docs/development.md)
- [Current scope and deferred work](docs/open-work.md)
- [Input provenance](manifest/inputs.json)

Original archives and extracted files live only in ignored `tmp/`. The repository
contains instructions, setup helpers, filenames and checksums, not game bytes.
