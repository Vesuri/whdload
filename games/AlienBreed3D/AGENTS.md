# AlienBreed3D

Alien Breed 3D (1995, Team 17, AGA) under WHDLoad: Psygore's direct slave 1.3
(08.01.2020), which loads the floppy, CD32 or Aminet 8-channel executable from `data/`,
relocates it into fast memory, gives it a minimal exec and dos of its own and patches it per
version. The original slave is by Psygore (game.conf `AUTHOR`, `UPSTREAM`); the install
package's source is encrypted, so `src/AlienBreed3D.s` is a reconstruction of both shipped
slaves ([development.md](docs/development.md)).
The repository's rules and shared docs are in the root `AGENTS.md` and `docs/index.md`;
this file and `docs/` here hold only what is specific to this game.

Read `docs/open-work.md` first.

The slave source is `src/` (Enhanced resolution: `src/palette.s` the palette builder,
`src/display.s` the screens and copper heads, `src/c2p.s` Kalms' c2p, `src/stride.s`
the line stride's sites and `src/sites.s` each view's geometry sites, both generated by
`tools/sites.py`, `src/hires.s` the 1x1 renderer's code, left out with `-DLORES`);
`tools/` is the development harness and never ships (`tools/exe.py` unpacks the game
executable for analysis, `tools/ab3d.py` drives the game on the shared server,
`tools/srcmatch.py` finds the published source's routines, `tools/baseline.sh` and
`tools/frametime.py` measure the frame rate and where a frame's time goes,
`tools/census.sh` and `tools/colours.py` are the colour census and the palette builder's
model, `tools/display.sh` and `tools/display.py` check the display against the original).
