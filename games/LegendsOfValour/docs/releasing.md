# Building the release archive

Run `make dist` in this directory (or `make dist GAME=LegendsOfValour` at the root;
`FORCE=1` replaces an existing archive). It builds the release slave and runs
`tools/release.py` (`game.sh` `game_dist`). Requires Python 3, the normal
vasm/WHDLoad/NDK build dependencies, and `lha`/Lhasa for extraction and CRC verification.
No LHA compressor is needed: the replacements use the standard uncompressed `-lh0-` method.

The input is the original installer, `tmp/archives/LegendsOfValour.lha` (`make unpack
ARCHIVES=<directory>` copies and verifies it, `inputs.sha256`). The output, in the
repository's ignored `dist/`, is `LegendsOfValourEnhanced-<version>-<YYYYMMDD>.lha` and its
`.sha256`, the version and date from the release slave's `$VER` string (`version_of` and
`date_of` of `common/tools/package_release.py`): for 1.1b,
`LegendsOfValourEnhanced-1.1b-20261009.lha`. The preinstalled 0837 archive is an input of
`make unpack` (the game data) but is not repackaged.

The command rebuilds the plain release slave (`make slave` with no `VASM_EXTRA`) and checks
its two-option menu, that `slv_info` carries the `$VER` version and date, and that
`release/ReadMe` has a `Changes in <version> (<date>)` entry. It prepends `release/ReadMe` to
the original ReadMe and updates the original memory requirement. Original credits (CFou!'s)
and installation notes remain.

Replaced records: `LegendsOfValourHd/LegendsOfValour.Slave`, `LegendsOfValourHd/ReadMe` and
the six game icons the installer offers, `LegendsOfValourHd/LegendsOfValour.{inf,infC,
colcfou,colcfou2,colcfou3,colcfou4}`. Each icon's tooltypes must be exactly `CUSTOM1=0`;
`tools/icon.py` parses the DiskObject and appends `CUSTOM2=64`, keeping the artwork,
NewIcon/ColorIcon data and every other byte. The Install script copies the chosen icon and
sets only its default tool, `Slave`, `PreLoad` and stack, so the installed icon runs with the
timing on; `CUSTOM2=0` restores the original timing. `python3 tools/icon.py ICON...` prints an
icon's tooltypes.

The archive keeps exactly its original entry names and order; every other compressed
record, including its metadata, is copied byte for byte (the Install script and the legacy
`.src` file stay unchanged). Before publishing, the staged archive passes Lhasa's full CRC
test, a comparison of every replaced entry's extraction with its source and the original,
the icons' tooltypes read back, and the unchanged-record/name/order checks. The replaced
records carry the packaging time, so rebuilt archives differ only in those records'
timestamps and header checksums. Packaging does not launch the game or alter installed
slaves, preferences or emulator sessions.

All original/generated bytes remain local: staging and builds are in the ignored `tmp/`,
and `dist/` is ignored. Never commit or automatically upload the archive.
`release/slaves.sha256` records the release slave (`make check`, `make record`).
