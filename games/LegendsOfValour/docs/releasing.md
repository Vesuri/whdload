# Building release archives

Run `python3 tools/release.py` from the repository (or use the script's absolute
path). Requires Python 3, make, the normal vasm/WHDLoad/NDK build dependencies,
and `lha`/Lhasa for extraction and CRC verification. No LHA compressor is needed:
the two replacements use the standard uncompressed `-lh0-` method.

Inputs and outputs:

| Local input | Local output |
|---|---|
| `tmp/LegendsOfValour.lha` | `dist/LegendsOfValour-1.1.lha` |
| `tmp/LegendsOfValour_v1.0_0837.lha` | `dist/LegendsOfValour_v1.1_0837.lha` |

The command rebuilds the normal release slave with empty VASMFLAGS and checks
its version and three-option menu. It prepends `whdload/ReadMe-1.1.txt` to each
original ReadMe and updates the original memory requirement. Original credits
and installation notes remain. Each archive retains exactly its original entry
names and order. Only the Slave and ReadMe entries are replaced; every other
compressed record, including its metadata, is copied byte-for-byte. In
particular, the install archive's legacy `.src` file stays unchanged.

Before publishing, both staged archives pass Lhasa's full CRC test, replacement
extraction comparisons, and unchanged-record/name/order checks. Outputs can be
regenerated; a successful run replaces earlier output archives. Packaging does
not launch the game or alter installed slaves, preferences or emulator sessions.

All original/generated bytes remain local: staging and builds are in ignored
`tmp/`, and `dist/` is ignored. Never commit or automatically upload either archive.
